# Tentang


<details close>
<summary><strong>Apa itu IDScript?</strong></summary>

IDScript merupakan sebuah bahasa pemograman yang didasarkan bahasa Indonesia yang digabungkan dengan teknologi python.

IDScript adalah bahasa pemograman berorientasi objek.
</details>

<details close>
<summary><strong>Latar Bekakang IDScript?</strong></summary>

Kami melihat banyak siswa/i yang belajar bahasa pemograman dari bahasa pemograman yang mungkin syntax nya dia saja tidak mengerti. Jadi kami buatlah bahasa pemograman yang berbasis bahasa Indonesia yang mudah dipahami sekaligus bisa menjadi bahan edukasi.

Projek kami opensource, hanya saja jika ada dan jika ingin merubah script kami harus ada persepakatan dan persetujuan kami. Agar tidak melenceng dari visi misi kami.

Silahkan untuk para guru atau pengajar untuk menggunakan teknologi kami sebagai bahan pelajaran anda sekalian

</details>

## Github atau Lokal

Cara pertama adalah mengeklon direkori dan memasuki direktori tersebut

```bash
git clone https://github.com/Elang-elang/IDScript.git
cd IDScript
```

Lalu menginstall secara lokal

```bash
pip install -e .
```

> Peringatan: Lebih baik gunakan virtual envirotmen karena mungkin saja ada beberapa perpustakaannya yang bisa saja berukuran berat

## Python (PIP)


Cara ini adalah cara yang mudah. Dengan seperti berikut saja anda telah menginstal nya

```bash
pip install IDScript
```

> Peringatan: Lebih baik gunakan virtual envirotmen karena mungkin saja ada beberapa perpustakaannya yang bisa saja berukuran berat
